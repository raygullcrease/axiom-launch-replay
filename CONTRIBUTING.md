# Contributing

Thanks for the interest. This is a small free tool, so the bar is simple.

- Bug reports: open an issue with your Windows version and the check that misfired.
- Token-check rules: a missed or wrong flag is a one-line fix in a pull request.
- Design and docs: the mockup sources live in `design/` and render with Node 20 (`npm install`, `node render.mjs all`).

By contributing you agree your contribution is MIT-licensed. No credentials, ever — keep it that way.
